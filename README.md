> 基于AI的智能股票交易系统，支持34个策略、情感分析、自动交易、实时监控

## 🎯 系统功能

### 核心功能
- **34个交易策略** - 趋势/动量/反转/波动/量能/模式/综合/短线/比赛
- **情感分析** - 143个关键词 + 215个股票专属关键词 + 11个数据源
- **股票关键词库** - 508只股票自动绑定关键词（基于akshare）
- **AI决策引擎** - 规则引擎 + AI增强（可选）
- **自动交易** - 动态止损(2倍ATR) + 移动止损(3%) + 比赛阶段自适应
- **策略优化** - Optuna贝叶斯优化
- **健康监控** - 策略衰减自动检测

## 🚀 快速开始

### 方式1: 直接运行
```bash

```

### 方式2: 打包版
