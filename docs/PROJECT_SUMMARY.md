# THS Trading AI - 项目总结

## 一、借鉴的开源项目

| 项目 | 用途 | 链接 |
|------|------|------|
| **akshare** | A股数据获取 | github.com/akfamily/akshare |
| **Optuna** | 策略参数优化 | github.com/optuna/optuna |
| **transformers** | NLP情感分析 | github.com/huggingface/transformers |
| **jieba** | 中文分词 | github.com/fxsjy/jieba |
| **Flask** | Web API框架 | github.com/pallets/flask |
| **ECharts** | 前端图表 | github.com/apache/echarts |

### 借鉴内容

| 来源 | 借鉴内容 | 应用位置 |
|------|----------|----------|
| akshare | 概念板块、行业板块数据 | stock_keyword_db.py |
| Optuna | TPE贝叶斯优化算法 | strategy_optimizer.py |

| jieba | 中文分词算法 | sentiment_analyzer.py |

## 二、自主开发的内容

### 核心模块

| 模块 | 文件 | 说明 |
|------|------|------|
| 自动交易引擎 | auto_trader.py | 订单执行、风控、止损止盈 |
| AI调度器 | ai_scheduler.py | 定时分析、自动交易 |
| AI决策大脑 | ai_brain.py | 策略选择、信号综合 |
| 情感分析 | sentiment_analyzer.py | 多源新闻、情绪分析 |
| 股票关键词库 | stock_keyword_db.py | 508只股票自动绑定关键词 |
| 策略优化 | strategy_optimizer.py | Optuna参数优化 |
| 健康监控 | strategy_health.py | 策略衰减检测 |
| 风控系统 | risk_manager.py | 止损止盈、仓位管理 |
| 比赛规则 | competition.py | T+1、涨跌停、整手 |

### 策略系统

| 类别 | 策略数 | 代表策略 |
|------|--------|----------|
| 趋势 | 5 | MA交叉、布林突破 |
| 动量 | 4 | RSI极端、MACD金叉 |
| 反转 | 4 | RSI背离、双底 |
| 波动 | 3 | 布林收缩、ATR突破 |
| 量能 | 3 | 放量突破、量价背离 |
| 模式 | 3 | 平台突破、缺口回补 |
| 综合 | 2 | 多因子、AI增强 |
| 短线 | 5 | 跳空高开、均值回归 |
| 比赛 | 5 | 强势回调、连板追踪 |
| **总计** | **34** | - |

### 自主创新

| 创新点 | 说明 |
|--------|------|
| 情绪+技术混合 | 规则80% + NLP 20% |
| 动态止损 | 基于ATR自动调整 |
| 比赛阶段自适应 | 激进/均衡/防守自动切换 |
| 批量选股 | AI自动筛选最优股票 |
| 健康监控 | 策略衰减自动检测 |
